Neon Vice Cover Studio turns a photo and a caption into a multi-panel poster in the style of a Vice City sunset: pick a layout, fill each panel with your own photo or a sample, crop and position every panel, write the caption, pick a colour grade, and export a PNG to share. All artwork is original, drawn in code — no Rockstar logos, art or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Upload photos, choose a layout (Hero split, Triptych, Four up, Single frame), a grade (Sunset, Neon, Dusk, Noir) and an export size (1080 x 1080, 1080 x 1350, 1920 x 1080), and press Export PNG. The app runs offline in a desktop browser from its own files — no network requests.
